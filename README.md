## Wedding Shedding links

Open `site-config.js`:

```js
window.AJAY_NXT_CONFIG = {
  weddingShedding: {
    website: "https://weddingshedding.github.io/._/",
    googleBusiness: "https://share.google/v7xGQRWmTwm0u1j0X",
    instagram: "PASTE_INSTAGRAM_LINK_HERE",
    facebook: "PASTE_FACEBOOK_LINK_HERE"
  }
};
```

Instagram and Facebook buttons are already present. Add the exact links later and they will activate automatically.

## Deploy

GitHub repository → Settings → Pages → Deploy from branch → `main` → `/(root)`.
